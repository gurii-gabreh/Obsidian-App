# ChatGPTで作成したObsidian Canvas

| フォルダ | 内容 |
|---|---|
| [servicenow-sub-agent](servicenow-sub-agent/) | ServiceNowリサーチアプリの内部構成・連関図・説明。 |

必要なフォルダをObsidianのVault内へ配置し、`.canvas` を開いてください。拡大・縮小、移動、編集ができます。各Canvasはテキストを内包し、別ノートや画像の依存はありません。GitHubのファイル画面は操作可能なCanvasビューアではありません。
