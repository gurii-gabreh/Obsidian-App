# アプリ作成の全体像

[app-architecture-flow.canvas](app-architecture-flow.canvas) をObsidianのVault内で開いてください。

目的・画面・処理・データ・安全・開発・公開・スマホの8カテゴリ、25項目をまとめた初心者向けのマップです。左側にカテゴリと短い説明、右側に選び方・具体例を置いています。

「必ず決める・確認すること」と「必要なら使う仕組み」を区別し、仕様、開発環境、テスト、バックアップ・復元、秘密情報、公開後の運用を含めています。

特定アプリの採用済み仕様ではなく、構成を選ぶためのチェックリストです。技術名は候補の例で、料金や制限は採用時に公式情報で確認してください。
